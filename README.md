## 为什么是这条缝（不是拍脑袋）
- 美区 App Store 实测（`tools/_appgap.cjs`，2026-09-15，iTunes 公开接口）：
  `body doubling` 关键词下 **166 个结果**，**前 10 名评论数中位数只有 34 条**，8/10 个 App 评论数 <5,000；
  上架时间集中在 **2023–2026**（dubbii 2023 / Lumi 2026-01 / EarlyBird 2026-01 / Beside 2026-02 / Momo 2026-08 = **0 条评论**）。
  → **需求刚被验证，赢家还没出现。**
- 对照：`ADHD planner` 前 10 中位 **45,728** 条评论（已被打满，放弃）；`habit tracker` 15,784。
- 真实先例：Hank Green **2025-07-23** 上线的 Focus Friend（虚拟角色陪你干活），一年 **6,895 条评论**。
- 行业面：前 10% App 拿走 **94.5%** 订阅收入（Adapty 2026）→ **必须窄到能当第一**，这正是选它的理由。

## 合规红线（必须守）
- ❌ 不做诊断/治疗/医疗宣称（苹果要求医疗类资质；`diagnosis`/`treatment` 字样一律不出现）。
- ❌ 不做"心理治疗""ADHD 治疗"定位；只做**习惯/专注陪伴工具**。
- ✅ 不采集健康数据、不做账户体系、**全部数据留本地**（少一类审核风险）。
- ✅ 若后期加 AI 对话，必须**明示 AI 身份 + 用户可见披露**（苹果 2026 指南）。

## 设备硬约束（来自老板的测试机）
| 项 | 值 |
|---|---|
| 测试机 | **iPhone X** |
| 系统 | **iOS 16.7.16** |
| 结论 | **部署目标锁 iOS 16.0**；**禁用 iOS 17/18 独有 API** |

**因此在代码层禁用**：`SwiftData`（17+）、`@Observable`（17+）、`ContentUnavailableView`（17+）、
iOS 17 新版 `ScrollView` API、`storekit` 新视图（17+）。
**改用**：`ObservableObject` + `@Published`、**Core Data 或 JSON 文件持久化**、iOS 16 版 SwiftUI 组件。
（另：截图交付仍需 6.9" 机型，由 CI 模拟器出图，不需要真机。）

## 技术栈与构建
- **UI**：SwiftUI（单 target，iOS 16.0+）
- **持久化**：本地 JSON / Core Data（无后端、无账号、零边际成本）
- **构建（关键：没有 Mac 也能做）**：**GitHub Actions 的 macOS 构建机**
  - **公共仓库 = 免费、不占额度**（私有仓库 macOS 走 10 倍倍率：2000 分钟 ≈ 200 macOS 分钟）
  - 备选：Codemagic 个人版每月送 500 分钟 M2
  - 真实先例：DEV 社区《I ship iOS apps to the App Store without owning a Mac》
- **上架费用**：Apple 开发者账号 **$99/年 ≈ ¥720**（**唯一硬花钱项，等成品能跑再付**）
